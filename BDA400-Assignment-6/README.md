## Project
Interactive R Shiny stock dashboard with Yahoo Finance historical OHLC data, daily/weekly/monthly aggregation, line/area/candlestick views, optional SMA overlays, RSI and MACD panels, and annotated Buy/Sell crossover signals. All other bars are Hold.

## Run
1. Install R and RStudio.
2. In R, execute: `install.packages(c("shiny", "ggplot2", "quantmod"))`
3. Set the working directory to this folder and run: `shiny::runApp(".")`
4. Try ticker AAPL, switch time frames, change SMA periods and toggle indicators.
